# Neve_project
nicolaegherciu224 — Website demo de marketing

Despre proiect

Acest repository conține codul unui website WordPress pe care l-am dezvoltat ca proiect personal (side project), pornind de la tema Neve.

Site-ul a fost creat pentru a-l ajuta pe prietenul meu,  (specialist marketing), să prezinte într-o prezentare a lui viziunea sa despre cum ar trebui să arate site-ul "perfect" pentru atragerea și conversia clienților — din perspectiva unui om de marketing, nu a unui developer.

Practic, am tradus în cod ideile lui despre:

structura ideală a unei landing page
elemente de encouragement/CTA pentru conversie
parcursul vizual al utilizatorului de la prima interacțiune până la acțiunea dorită

Tehnologii folosite
WordPress — platforma de bază
Neve — tema de bază (open-source, licență GPLv2+), dezvoltată de ThemeIsle/CodeinWP
CSS custom — stilizări adiționale, adăugate peste tema de bază
JavaScript custom — interacțiuni/animații adiționale
Elementor - builderul folosit in Wordpress

Ce am personalizat eu

Pe lângă tema Neve (nemodificată la nivel de core), am adăugat:

secțiune hero custom cu animații CSS
buton CTA sticky cu comportament controlat prin JS
efecte de scroll/parallax pe anumite secțiuni
ajustări de tipografie și paletă de culori conform brandingului discutat
formular de contact optimizat pentru conversie

Instalare locală
Clonează acest repository:

bash
   git clone https://github.com/nicolaegherciu224/Neve_project.git

Instalează un mediu local WordPress (ex: LocalWP, XAMPP, Docker).
Copiază folderul temei în wp-content/themes/.
Activează tema din panoul de administrare WordPress.

Scopul proiectului

Acest proiect nu este un produs comercial, ci un exercițiu personal de a:
exersa customizarea unei teme WordPress prin CSS/JS,
traduce cerințe non-tehnice (viziunea de marketing a unui prieten) în soluții tehnice concrete,
construi un portofoliu de lucru cu WordPress.
